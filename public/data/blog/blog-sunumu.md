# Blog Yazısı Başlığı

Blog yazılarında da projelerdeki gibi tüm zengin formatlama özelliklerini kullanabilirsiniz.

> Blog yazılarında alıntılar, okuyucunun dikkatini önemli noktalara çekmek için harikadır.

-----

## Kod Paylaşımı

```typescript
// Blog yazısında kod örneği verilebilir
const blog = {
    title: "Harika Bir Yazı",
    author: "Hamza",
    likes: 999
};
```

## Yapılacaklar

[x] Yazıyı planla
[x] Görselleri hazırla
[ ] Yayınla ve paylaş

Diğer tüm özellikler (Tablolar, Spoiler, Resimler) burada da geçerlidir.
