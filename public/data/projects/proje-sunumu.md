# Ana Başlık Örneği
Burası projenin ana giriş bölümü. Projenin ne hakkında olduğunu anlatan çarpıcı bir giriş paragrafı.

> Bu proje, Custom Markdown motorunun yeteneklerini sergilemek amacıyla hazırlanmıştır.
> Blok alıntılar (blockquote) bu şekilde görünür ve dikkat çekici bilgiler için kullanılır.

-----

## Metin Stilleri ve Formatlama

Yazılarınızda **kalın (bold)** vurgular yapabilir, *italik (italic)* ile nüans katabilir veya __altı çizili (underline)__ metinler kullanabilirsiniz. 

Hatta sürprizler için ||gizli içerik (spoiler)|| özelliğini kullanabilir (üzerine gelince görünür) veya ~vazgeçilmiş fikirleri (strikethrough)~ bu şekilde gösterebilirsiniz.

-----

## Listeler ve Organizasyon

Yapılacaklar listesi:
[x] Markdown motorunu yaz
[x] Tasarımı güzelleştir
[ ] Dünyayı ele geçir
[ ] Kahve iç

Özellik listesi:
- Hızlı ve hafif
- Tamamen özelleştirilebilir
  - İç içe listeler
  - Detaylı hiyerarşi

## Kod Blokları

Yazılım projelerinizi anlatırken kod bloklarını kullanabilirsiniz:

```csharp
public class Gamer : Human
{
    public string FavoriteGame { get; set; }

    public void Play()
    {
        Console.WriteLine("Game on!");
    }
}
```
